    Make a small model that answers in your JSON

    1. Task - describe the job and the output structure (JSON Schema).
    2. Examples - add or import input → expected output pairs. 50-500 is typical.
    3. Model - pick an open-source base model; bigger is smarter but slower.
    4. Train - LoRA fine-tuning on your GPU, scored on held-out examples. Try it on your own inputs.
    5. Export - a GGUF model for Ollama or llama.cpp plus PHP, C# and Python clients.
